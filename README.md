# 🎤 Voice Assistant using Python

## 📌 Project Description

This is a Python-based Voice Assistant that listens to the user's voice, recognizes commands, and performs basic tasks such as greeting the user, telling the current time and date, and searching Google. The project uses Speech Recognition for voice input and Text-to-Speech for voice responses.

---

## 🚀 Features

- 🎤 Voice Recognition using Microphone
- 🔊 Text-to-Speech Response
- 👋 Responds to "Hello"
- 🕒 Tells the Current Time
- 📅 Tells the Current Date
- 🌐 Searches Google for a User Query
- ❌ Handles Unknown Commands
- ⚠️ Handles Voice Recognition Errors
- 🔁 Continuous Listening Mode
- 🚪 Exit Command ("exit" or "stop")

---

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/OIBSIP_Voice_Assistant.git
```

2. Open the project folder

3. Install the required libraries

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python voice.py
```
